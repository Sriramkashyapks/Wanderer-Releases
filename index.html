How to Install on Android

3 simple steps to get Wanderer up and running on your Android phone.

1

Download APK

Tap the Download APK (v0.3) button above on your Android phone browser.

2

Allow Unknown Apps

When prompted by Chrome/Android, tap Settings and switch on "Allow from this source".

3

Open & Wander

Tap Install. Once completed, open Wanderer, sign in with Google or continue as guest to start exploring!

Version History & Updates

Track release notes and feature improvements.

v0.3 (Latest Release - Oct 2026) Current Release
  • Native Android Manifest Intent-Filter: Configured wanderer:// BROWSABLE scheme intent filter in AndroidManifest.xml for seamless standalone APK OAuth redirects.
  • Linking Deep-Link Event Listener: Added React Native Linking listener to capture OAuth tokens directly from Chrome intent redirections.
  • Google & Supabase OAuth Integration: One-tap Google Sign-in with native deep-linking support (wanderer://).
  • Automatic Guest-to-User Trip Migration: Offline guest trips, places, timeline events, and notes seamlessly transfer upon sign-in.
  • NestJS Auth Sync Engine: Backend user profile synchronization (POST /api/v1/auth/sync) with JWT authentication guards.
  • Non-Blocking UI Loader & 6s Timeout: Immediate loading state transitions and AbortController timeout protection on all API calls.
  • Auth Token Protection: Updated cache clearing to preserve Supabase authentication session tokens.
